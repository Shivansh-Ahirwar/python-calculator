# Python Calculator

A simple desktop calculator built using Python and Tkinter.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Percentage
- Clear (`AC`)
- Delete single digit (`⌫`)
- Equals (`=`)
- Keyboard support
- Division-by-zero error handling
- Dark calculator interface
- Rounded buttons and hover effects

## Technologies Used

- Python 3
- Tkinter

## How to Run

Make sure Python 3 is installed.

Run the calculator using:

```bash
python3 calculator.py
